# 前端工作台页面划分

更新：2026-10-13。

## 页面与使用流程

首页 `/` 提供「开始生活圈体检」入口和三步流程；服务探测仍可在首页查看。
工作台沿用 `/isochrone.html`，以 hash 区分独立视图，不新增前端构建链或后端路由。

| 页面 | 地址 | 内容 |
| --- | --- | --- |
| 新建体检 | `/isochrone.html#setup` | 预置样例、地址搜索、可折叠坐标输入、地图选点入口、出行方式、时长、设施类别 |
| 生活圈地图 | `/isochrone.html#map` | 地图、设施 / 盲区 / 热力等图层、可折叠图例、返回参数与报告入口 |
| 体检报告 | `/isochrone.html#report` | 来源徽标、综合评分、结论摘要、六维图表、当前分析导出 |
| 设施明细 | `/isochrone.html#facilities` | 类别筛选、表头排序、每页 20 条的本地分页 |
| 服务盲区 | `/isochrone.html#blind` | 盲区清单、缺失设施、地图定位 |
| 运行详情 | `/isochrone.html#details` | 进度、顶点、真实路径按需查询、等时圈 / 完整体检分别计量、预算、口径提示 |
| 系统设置 | `/isochrone.html#settings` | 数据模式、浏览器端 AK 本机配置、服务探测与接口文档链接 |

「生成完整体检报告」调用现有 `/api/analysis`，成功后打开报告。
「仅计算等时圈」调用现有 `/api/isochrone`，成功后打开地图，不生成新的评分报告。
预置样例仅载入中心点，仍需点击生成按钮。地图选点后可通过地图页的「修改地点与参数」返回设置。

## 实现约定

- `workspace.js` 只负责页面显示、标题、导航、历史记录和状态消息；**导航不发请求**。
- `isochrone.js` / `report.js` 仍各自持有原来的地图和报告状态。不复制结果，不改请求参数或后端评分。
- 业务节点的 `id` 保留，使用 `data-view` 在呈现层分组。隐藏的视图既不可见，也不进入键盘焦点序列。
- 同一标签页内切换、前进 / 后退保留结果；刷新页面后恢复为空态。报告不写入 localStorage。
- 地图重新显示时调用 `refreshViewport()`，修复隐藏容器尺寸为零的问题。
- 盲区定位使用 `focusOn()` 平移视野，不用 `setCenter()`，避免改变分析原点。
- 本地分页仅对本次已返回记录分页，不翻百度接口页；CSV / JSON 导出仍包括当前整份分析，不受当前页或筛选影响。
- 桌面固定侧栏；移动端固定顶部导航。同一组独立页面替代旧的底部抽屉表现。这是对 PRD FR-106「地图 + 底部抽屉」的呈现方式调整，保留移动端操作、44 px 常规触摸热区和结果可达性；旧抽屉代码 / DOM 钩子保留但在工作台禁用。
- 不加载外部字体、图片或 CDN；离线横幅、示意图标注、来源徽标、配额确认和合规页脚保留。

## 验证

- `pytest -q`：519 个测试通过（包含新的路由 / DOM / 资源 / 分页契约测试）。
- 可选真实浏览器检查：安装 `playwright` 并准备 Chromium，启动零配置服务后运行：

  ```bash
  python tools/check_workspace.py --base-url http://127.0.0.1:8000
  # 或指定已有浏览器
  python tools/check_workspace.py --base-url http://127.0.0.1:8000 --browser-path /path/to/chromium
  ```

  覆盖空态、导航 / 历史、结果保留、类别筛选 / 排序、本地分页、盲区定位、JSON / CSV 导出、
  390 / 768 / 1024 / 1440 px 横向溢出、仅等时圈路径及 API 失败提示。
- 本次浏览器验证使用零配置合成数据和 SVG 地图；未使用真实百度 AK 验证 live 地图。
